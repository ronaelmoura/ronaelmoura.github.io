# Portfólio — Ronael Moura

Portfólio profissional de **Ronael Moura**, Desenvolvedor Full Stack Júnior com foco em **React, Node.js, Express, APIs REST e MySQL**.

O site apresenta projetos autorais de front-end, back-end e produto, com o **Ronas Desk** como principal estudo de caso técnico.

## Portfólio online

https://ronaelmoura.github.io/

## Destaques

- **Ronas Desk** — plataforma Full Stack de Help Desk em produção para demonstração
- **Nexo** — dashboard financeiro com React e TypeScript
- **StockFlow API** — API de estoque e pedidos com Node.js, Express e MySQL
- **ClimaZen** — landing page responsiva com foco em experiência e conversão
- **Ronas Tech** — projeto de tecnologia e soluções digitais para pequenos negócios

## Stack principal

- React
- JavaScript / TypeScript
- Node.js
- Express
- MySQL
- APIs REST
- Docker
- Git e GitHub

## Qualidade e engenharia

O portfólio também apresenta decisões de arquitetura, segurança, testes e deploy do Ronas Desk. O projeto principal possui **370 testes automatizados**, sendo **316 no backend e 54 no frontend**.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Validação e build

```bash
npm run lint
npm run build
```

O deploy é feito automaticamente no **GitHub Pages** por GitHub Actions após alterações na branch `main`.
